# bizhub-diff

Tools for exporting and comparing configuration data from Konica Minolta bizhub devices.

## Files

### `bizhub-get.py`

Exports configuration settings directly from a bizhub web interface and produces a JSON file suitable for comparison.

The script:

- Logs into the printer's Web Connection interface.
- Loads the JavaScript application used by the device.
- Enumerates available configuration pages and menus.
- Retrieves configuration data from the printer APIs.
- Produces a JSON document containing all discovered settings.
- Can write the result to a file or to standard output.

### `bizhub-diff.html`

A standalone browser-based configuration comparison tool.

The tool:

- Loads two JSON exports generated by `bizhub-get.py`.
- Compares all configuration values.
- Detects:
  - Added values
  - Removed values
  - Changed values
  - Moved array items
- Displays menu information and configuration paths.
- Supports filtering by:
  - Difference type
  - Scope (Admin/User)
  - Menu location
  - Left value
  - Right value
- Supports configurable array discriminators so arrays can be matched by logical identifiers instead of array position.

No installation is required. Open `bizhub-diff.html` in a modern browser and select two exported JSON files.

## Requirements for `bizhub-get.py`

Python 3.11+ is recommended.

Additional Python modules:

```bash
pip install jsrun
```

The script uses only standard library modules apart from `jsrun`.

## Exporting a configuration

### Interactive password prompt

```bash
python bizhub-get.py printer.example.com --out-file printer.json
```

The script will prompt for the administrator password.

### Password on command line

```bash
python bizhub-get.py printer.example.com \
  --password MyPassword \
  --out-file printer.json
```

### Output to stdout

```bash
python bizhub-get.py printer.example.com
```

## Command line options

### Host

Required printer hostname or IP address.

```bash
python bizhub-get.py 192.168.1.100
```

### `--port`

Connect using a custom port.

```bash
python bizhub-get.py 192.168.1.100 --port 8080
```

### `--use-ssl`

Use HTTPS instead of HTTP.

```bash
python bizhub-get.py printer.example.com --use-ssl
```

### `--insecure`

Disable TLS certificate validation.

Useful when the printer uses a self-signed certificate.

```bash
python bizhub-get.py printer.example.com \
  --use-ssl \
  --insecure
```

### `--path`

Base Web Connection path.

Default:

```text
/wcd/
```

### `--out-file`

Write the export to a file.

```bash
python bizhub-get.py printer.example.com --out-file config.json
```

### `--password`

Provide the administrator password directly.

```bash
python bizhub-get.py printer.example.com --password SecretPassword
```

If omitted, the password is requested interactively.

## Typical workflow

### Export printer A

```bash
python bizhub-get.py 192.168.1.10 --out-file printer-a.json
```

### Export printer B

```bash
python bizhub-get.py 192.168.1.11 --out-file printer-b.json
```

### Compare

1. Open `bizhub-diff.html`.
2. Select `printer-a.json` as the left configuration.
3. Select `printer-b.json` as the right configuration.
4. Click **Compare**.
5. Review the reported differences.

## Notes

- The JSON format consumed by `bizhub-diff.html` is the format produced by `bizhub-get.py`.
- The comparison tool runs entirely in the browser; no data is uploaded anywhere.
- Array discriminator rules can be adjusted in the **Array discriminators** section to improve matching of model-specific configuration structures.
